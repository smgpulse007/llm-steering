# Lesson 7: Advanced Methods

The advanced roadmap starts after ActAdd and mean-difference vectors are stable.

Important next methods:

- Activation patching: move activations between clean and corrupted runs to diagnose causal sites.
- SEA: spectral activation editing that uses covariance structure from positive and negative examples.
- SAE-guided steering: use sparse autoencoder features to steer more interpretable directions.
- Conditional activation steering: apply interventions only when a condition is detected.

These methods are not claimed as fully implemented in the current release. They are research-backed roadmap items.

## Rule For This Repo

A method becomes supported only after the repo has code, tests, artifacts, and documentation that prove the implemented behavior.
